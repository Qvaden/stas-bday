# 🎂 С ДР, Стас! — сайт-поздравление

Угарный одностраничный сайт для Стаса на 27-летие. Сайт с анимациями, мемами и пожеланиями.

## 🚀 Стек

- **React 19** + **Vite** — быстрая сборка
- **GSAP + ScrollTrigger** — плавные scroll-анимации
- **Кастомный CSS** — никаких библиотек, всё своё

## ✨ Что внутри

- 🎬 **Hero** — гигантская анимация имени Стаса с возрастом
- 🌟 **Кастомный курсор** — неоновый, с эффектом наведения
- 🎊 **Конфетти** — постоянный фон-салют
- 📜 **27 причин** — почему Стас — легенда
- ⏳ **Таймлайн** — 0 → 27 лет жизни
- 💫 **Пожелания** — от всей души
- 😂 **Мемы** — mix русских, gen-z и абсурда
- 💌 **Секретное послание** — личное письмо

## 🛠️ Локальный запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173/stas-bday/`

## 📦 Сборка

```bash
npm run build
```

Результат в папке `dist/`

## 🌐 Деплой на GitHub Pages

### 1. Создай репозиторий

На https://github.com/new создай репо с именем `stas-bday` (Public).

### 2. Подключи локальный репозиторий

```bash
git init
git add .
git commit -m "🎂 initial: сайт для Стаса"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/stas-bday.git
git push -u origin main
```

### 3. Включи GitHub Pages

1. Зайди в **Settings → Pages**
2. Source: выбери ветку `gh-pages` (она появится после первого деплоя)
3. Save

### 4. Задеплой

Перед деплоем замени `YOUR_GITHUB_USERNAME` в `package.json` на свой GitHub-логин.

```bash
npm run deploy
```

Сайт будет доступен по адресу:
`https://YOUR_USERNAME.github.io/stas-bday/`

## 🎨 Как кастомизировать

Открой `src/data/content.js` и поменяй:
- **HERO** — имя, возраст, подзаголовок
- **REASONS** — список причин (можно добавить/убрать)
- **TIMELINE** — этапы жизни
- **WISHES** — пожелания
- **MEMES** — мемы
- **SECRET_LETTER** — личное послание (там `[имя лучшего друга]` — замени на своё)

Все правки подхватятся автоматически — никаких дополнительных файлов трогать не нужно.
